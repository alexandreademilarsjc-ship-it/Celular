# Celular

Controle de Gastos e Ganhos — um app web simples e responsivo (funciona no navegador do celular) para registrar gastos e ganhos, acompanhar o saldo e ver os gastos por categoria.

## Como usar

Abra `index.html` em um navegador. Não precisa de servidor nem instalação — os dados ficam salvos localmente no navegador (`localStorage`).

## Funcionalidades

- Registro de gastos e ganhos com descrição, valor, categoria e data
- Resumo com total de ganhos, total de gastos e saldo
- Filtro por mês
- Gastos por categoria com percentual
- Lista de lançamentos com opção de exclusão
